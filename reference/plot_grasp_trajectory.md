# Plot the Q trajectory across GRASP iterations, with running maximum.

Plot the Q trajectory across GRASP iterations, with running maximum.

## Usage

``` r
plot_grasp_trajectory(res, ...)
```

## Arguments

- res:

  an \`lcda_grasp_result\` or \`lcda_gr_result\` object.

- ...:

  further arguments passed to \[plot()\].

## Value

invisibly, a data frame of per-iteration Q and running maximum.
