# Plot the evolution of selection probabilities p_k across iterations.

Plot the evolution of selection probabilities p_k across iterations.

## Usage

``` r
plot_reactive_pk(res, ...)
```

## Arguments

- res:

  an \`lcda_gr_result\` object.

- ...:

  further arguments passed to \[matplot()\].

## Value

invisibly, the p_k history matrix.
